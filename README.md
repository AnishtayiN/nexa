# 📡 نکسا | NEXA

پخش‌کنندهٔ سادهٔ IPTV و سازندهٔ خودکار پلی‌لیست‌های M3U. داده‌ها از API عمومی پروژهٔ [iptv-org](https://github.com/iptv-org/iptv) خوانده می‌شوند؛ این مخزن فایل ویدیویی میزبانی یا بازپخش نمی‌کند.

## قابلیت‌ها

- ساخت روزانهٔ پلی‌لیست‌ها با GitHub Actions
- پلی‌لیست فارسی و یک نسخهٔ گسترده‌تر فارسی + کردی
- خروجی جداگانهٔ HD و SD
- حذف URLهای تکراری، فیلتر محتوای علامت‌گذاری‌شده به‌عنوان NSFW و کنترل سالم‌بودن خروجی
- جست‌وجو، دسته‌بندی، علاقه‌مندی‌ها، اشتراک‌گذاری کانال و بارگذاری M3U دلخواه در پخش‌کننده
- انتخاب کیفیت دستی یا خودکار برای استریم‌های HLS چندکیفیته
- بدون API پولی، سرور اختصاصی یا وابستگی پایتونیِ اضافی

## فایل‌های خروجی

| فایل | محتوا |
| --- | --- |
| `playlist.m3u` | زبان فارسی (`fas`) |
| `playlist_hd.m3u` | کانال‌های HD نسخهٔ فارسی |
| `playlist_sd.m3u` | کانال‌های SD و کیفیت‌های نامشخص نسخهٔ فارسی |
| `playlist_extended.m3u` | فارسی + کردی (`fas,kur`) |
| `playlist_extended_hd.m3u` | کانال‌های HD نسخهٔ گسترده |
| `playlist_extended_sd.m3u` | کانال‌های SD و کیفیت‌های نامشخص نسخهٔ گسترده |

نسخهٔ گسترده به‌صورت پیش‌فرض در پخش‌کننده انتخاب شده است؛ نسخهٔ فقط فارسی هم از منوی منبع در دسترس است. تعداد شبکه‌ها با تغییر داده‌های upstream ممکن است روزبه‌روز عوض شود.

در منوی **کیفیت** روی تصویر، برای استریم‌های HLS چندکیفیته می‌توان حالت خودکار یا یکی از رزولوشن‌های واقعی همان استریم را انتخاب کرد؛ برای کاهش مصرف، رزولوشن پایین‌تری بگذارید. اگر لینک کیفیت ثابت داشته باشد، در صورت وجود لینک‌های جایگزین همان شبکه، آن‌ها نیز در منو نمایش داده می‌شوند. اگر گزینه‌ای برای تغییر وجود نداشته باشد، به‌جای منوی غیرفعال، وضعیت کیفیت ثابت نمایش داده می‌شود؛ نشان آن در موبایل فشرده است و برای پوشاندن کمتر تصویر، توضیح طولانی پنهان می‌ماند. این برنامه نمی‌تواند کیفیت تازه‌ای از اینترنت بسازد. در Safari و پخش HLS بومی، کیفیت را خود مرورگر تطبیق می‌دهد و انتخاب دستی رزولوشن‌های داخلی استریم در دسترس نیست.

## اجرا روی سیستم شخصی

Python نسخهٔ 3.10 یا جدیدتر کافی است؛ نصب پکیج لازم نیست:

```bash
python3 iptv_builder.py
python3 -m unittest discover -s tests -v
```

برای انتخاب زبان‌های دیگر، کدهای زبان را با کاما جدا کنید. کدهای رایج: `fas` فارسی، `kur` کردی، `ara` عربی، `eng` انگلیسی، `ell` یونانی و `tur` ترکی.

```bash
python3 iptv_builder.py --langs fas,kur,ara --extended-langs fas,kur,ara
```

تنظیمات را می‌توان از طریق آرگومان‌های بالا یا متغیرهای محیطی `LANGS`، `EXTENDED_LANGS`، `OUTPUT_DIR`، `CHANNELS_URL`، `FEEDS_URL` و `STREAMS_URL` تغییر داد. برای ساخت همهٔ زبان‌ها، مقدار زبان را `all` بگذارید؛ این کار می‌تواند پلی‌لیست بسیار بزرگی بسازد.

## بروزرسانی و میزبانی رایگان

Workflow موجود در `.github/workflows/python-app.yml` هر روز و پس از تغییر کد اجرا می‌شود. برای انتشار خروجی‌ها از توکن شخصی استفاده نمی‌کند؛ GitHub Actions با مجوز محدود `contents: write` و `GITHUB_TOKEN` داخلی خودش فایل‌ها را commit می‌کند.

برای انتشار رایگان رابط وب با GitHub Pages:

1. در مخزن به **Settings → Pages** بروید.
2. روش **Deploy from a branch** را انتخاب کنید.
3. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید.

`index.html` و فایل‌های M3U کنار هم هستند و به سرویس backend نیاز ندارند. هنگام استفاده از فهرست دلخواهِ میزبانی‌شده در دامنه‌ای دیگر، آن میزبان باید دسترسی CORS را مجاز کرده باشد.

## پخش و حقوق محتوا

این پروژه فقط پیوندهایی را که در فهرست عمومی upstream موجودند جمع‌آوری می‌کند؛ استریم‌ها در این مخزن میزبانی نمی‌شوند. در دسترس‌بودن، کیفیت، رایگان‌بودن یا مجازبودن هر پیوند در همهٔ کشورها تضمین نمی‌شود؛ ممکن است بعضی شبکه‌ها از نظر جغرافیایی محدود، موقتاً قطع یا نیازمند مجوز باشند. فقط از شبکه‌هایی استفاده کنید که پخش آن‌ها برایتان مجاز است و شرایط صاحب محتوا را رعایت کنید.
